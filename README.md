# Currency Converter in C

A simple command-line Currency Converter application developed in C. This program allows users to convert amounts between five different currencies: Indian Rupee (INR), US Dollar (USD), Euro (EUR), British Pound (GBP), and Japanese Yen (JPY).

## Features

* Convert between 5 major currencies.
* Menu-driven interface for easy navigation.
* Uses a two-dimensional array to store exchange rates.
* Supports multiple conversions in a single execution.
* Input validation for currency selection.
* Option to exit the application at any time.

## Technologies Used

* C Programming Language
* Standard Input/Output Library (`stdio.h`)

## How It Works

1. Select the source currency.
2. Select the target currency.
3. Enter the amount to be converted.
4. The program calculates and displays the converted amount based on predefined exchange rates.

## Note

The exchange rates used in this project are hardcoded and may not reflect real-time market values. To ensure accuracy, the rates should be updated periodically.
